05 / Correction Learning from residual autocorrelation
Error Decomposition
Pushing Further — The 40% Gain.
TIDE Corrector (batch)
95.5 MW
−20.9% · Zero-parameter filter · Uses recent error history
ARDRegression (sequential)
68.9 MW
−40.4% · Requires true err_lag_1 feedback
The key insight: Residual errors have serial correlation ρ = 0.79 (hour t → t+1). This means the error signal is learnable — if DLinear was wrong by +X MW at hour 0, it is likely wrong in the same direction at hour 1.
The constraint: TIDE's 20.9% improvement comes from access to recent error history. ARDRegression with the same features but no error history adds nothing. The dominant signal is time-based autocorrelation, not weather or calendar patterns.
Streaming Opportunity
A streaming architecture — correcting forecast hour-by-hour as actuals arrive — could unlock the full +40% error correction potential in production.
ρ = 0.79 · error autocorrelation is intra-day only · not exploitable for day-ahead batch
06 / Production From research to operator dashboard
Deployment Architecture
Interpretable & Production-Ready.
01
DecomEngine
Every forecast is decomposable: trend + seasonal + DOW offset + error correction. Operators can see exactly why a value was predicted — no black box.
02
Web Application
FastAPI backend + dashboard. GridCo dispatchers use it daily — forecast auto-fills the dispatch schedule. Operators review, edit, or override in ~1 minute.
03
Semi-Annual Retrain
Designed for 6-month retrain cycle or when rolling MAE degrades >10%. Adaptive L1/L7 trend absorbs short-term shifts between retrains.
